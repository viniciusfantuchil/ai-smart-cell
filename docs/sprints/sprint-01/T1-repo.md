## Objetivo
Repositório `ai-smart-cell` com o kit, as issues do Sprint 1 e o quadro de acompanhamento.

## Escopo
- [ ] Instalar Git, `gh` (GitHub CLI) e VS Code no Windows do NUC.
- [ ] Criar o repo público `ai-smart-cell` e proteger `main` exigindo PR.
- [ ] Copiar o kit para a raiz; commit num branch `t1-kit`, PR e merge.
- [ ] `gh auth refresh -s project` e rodar `tools/create_sprint1_issues.sh` e `tools/setup_github_project.sh`.
- [ ] Preencher a seção Status do README e a data de início em `docs/etapas/etapa-01.md`.
